# Visão do Dashboard Analítico (Trade Marketing)

Este projeto foi desenhado para que os dados extraídos pelo `prompt-classificador.md` alimentem o banco de dados SQL e, consequentemente, um painel no Power BI.

**Principais KPIs (Indicadores) a serem visualizados:**
1. **Taxa de Conversão do Agente:** Quantos "Sim" recebemos em relação ao total de padarias contatadas.
2. **Nuvem de Objeções:** Gráfico de barras mostrando as maiores barreiras de entrada (ex: "Falta de Espaço" vs "Marca Desconhecida").
3. **Preferência de Sabor:** Qual produto atrai mais a curiosidade inicial no B2B (ex: Guaraná da Amazônia vs Laranja Pera com 10% de suco).
